# 墨排 · MD2WeChat

Markdown 一键转微信公众号排版工具。纯前端、零依赖、无需注册。

- `index.html` — 工具主界面（左右分栏编辑器）
- `landing.html` — SEO 落地页
- `renderer.js` — Markdown → 微信内联样式 HTML 渲染器 + 主题引擎
- `app.js` — 前端交互
- `server.js` — 本地开发服务器：`npm run dev`

本地预览：`npm run dev` 后访问 http://localhost:7100
