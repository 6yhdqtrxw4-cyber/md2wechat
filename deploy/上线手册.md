# 墨排 · 5 分钟零成本上线手册

> 目标：产品挂到公网，拿到可分享的正式链接。总成本 ¥0（域名可后补）。

---

## 方案 A：GitHub Pages（推荐 · 免费 · 5 分钟）

### 第 1 步：建仓库
1. 打开 https://github.com/new
2. 仓库名填 **`md2wechat`**，选 Public，创建

### 第 2 步：上传文件
把本目录下这 5 个文件传上去（网页版直接拖）：
```
index.html  landing.html  renderer.js  app.js  robots.txt
```
> 上传后把 `landing.html` 重命名为 `index.html`（原 index.html 改名为 `app.html`，并把 landing.html 里两处 `href="index.html"` 改为 `href="app.html"`）。

### 第 3 步：开 Pages
1. 仓库 → **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch** → Branch 选 `main` / `(root)` → Save
3. 等 2 分钟，访问 `https://你的用户名.github.io/md2wechat/`

✅ 上线完成。把 V2EX 帖里的链接换成这个地址即可发帖。

---

## 方案 B：自定义域名（¥55/年 · 上线后 1 周内做）

1. 腾讯云 / 阿里云搜域名，推荐 **`moipai.com` / `moipai.cn` / `mopai.app`**（未被注册，品牌呼应「墨排」）
2. 买完后：DNS 加一条 **CNAME 记录** → 填 `你的用户名.github.io`
3. 仓库根目录加文件 `CNAME`（内容就一行：域名）
4. Settings → Pages 里 Custom domain 填入域名，勾选 Enforce HTTPS

> 上线后记得把 `sitemap.xml` 和 `robots.txt` 里的 `REPLACE_DOMAIN` 替换成正式域名，然后去 [Google Search Console](https://search.google.com/search-console) 和 [百度搜索资源平台](https://ziyuan.baidu.com) 提交 sitemap——SEO 流量的起点。
